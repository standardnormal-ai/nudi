nudi builds one deterministic instruction for the native Harbor agent. This
file is not a separate model call, and it does not draft that instruction.

Every condition tells the native agent to find a reward hack. `full` adds only
the supplied loophole details. `minimal` adds only the supplied short hint.
`none` adds no extra hint and includes no Inspector findings and no privileged
material. No-hint attempts receive no broader capture than selected artifact
declarations.

The native agent reasons in its original harness, under the shared queue,
credentials and spending cap. A reward, a written file, or a model flag is
not evidence.
