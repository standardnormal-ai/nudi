nudi builds one deterministic instruction for the native Harbor agent. This
file is not a separate model call, and it does not draft that instruction.

Every instruction tells the native agent to find a reward hack. Full and
minimal guidance each belong to one Inspector candidate. Full adds only that
candidate's loophole details. Minimal adds only that candidate's short hint.
Neither receives the static hack-family checklist or another candidate's hint.
The no-hint instruction is one discovery stream for the environment. It adds
the static checklist, which is not exhaustive, and no Inspector findings and
no privileged material. Every instruction captures the same files: the task's
declared artifacts and those the Inspector selected once from the original
task, before any episode. The native agent never sees that selection.

The native agent reasons in its original harness, under the shared queue,
credentials and spending cap. A reward, a written file, or a model flag is
not evidence. Discovery stops at its first evidenced exploit. A candidate
stops only when the Inspector attributes that exploit to the candidate.
Attribution compares the observed mechanism with the candidate's retained
description and full guidance and cites the retained check. A repeated
mechanism, a candidate id, or a success flag does not attribute it. The
minimal and no-hint actors do not receive that description or full guidance.
